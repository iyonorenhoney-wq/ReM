# Rem ホームページ

建設業の信頼感と清潔感を重視した、ReM BUILD PARTNERのブランドTOPページです。
HTML、CSS、JavaScriptだけで作成した静的サイトなので、`index.html` をブラウザで開くだけで確認できます。

## 作成したもの

- スマホファーストのTOPページ
- レスポンシブ対応
- 施工事例のダミーデータ
- 見た目のみのお問い合わせフォーム
- スマホ用の固定お問い合わせ導線
- ロゴ画像を使ったブランドファーストビュー
- スクロール時の静かな表示アニメーション

## ファイル構成

```text
rem-homepage/
├── index.html
├── styles.css
├── script.js
├── README.md
└── assets/
    └── rem-logo.jpg
```

## 確認方法

`index.html` をブラウザで開いてください。

## 注意点

お問い合わせフォームは見た目のみです。
実際にメール送信やデータ保存をするには、フォーム送信用の仕組みを追加する必要があります。
